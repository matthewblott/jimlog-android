# Jimlog Android Application

The Android front end for the Jimlog(https://github.com/matthewblott/jimlog-svelte) application. This project has been archived as the main application is no longer powered by SvelteKit which is what this works with. The new Android application is also now part of the main Jimlog application. All new development can be found [here](https://github.com/matthewblott/jimlog-svelte).
